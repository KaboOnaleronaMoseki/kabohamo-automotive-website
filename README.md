Kabohamo Automotive Website

## About the Project

This project is a responsive business website created for Kabohamo Automotive. The website helps customers learn about the company's vehicle-related services and contact the business for assistance.

Kabohamo Automotive provides support with:

- Vehicle licence renewals
- Vehicle registration
- South African number plates
- Logistics and fleet-related enquiries

The website is designed to be simple to navigate on desktop computers, tablets, and mobile devices. It uses a consistent layout, shared navigation, service information, enquiry forms, contact details, and business images.

## Website Pages

### Home

Introduces Kabohamo Automotive and provides quick links to the main services, enquiry page, company information, frequently asked questions, and customer journey.

### About Us

Explains the company's purpose, mission, vision, values, and team support structure.

### Services

Describes the main services offered, including licensing, registration, number plates, and logistics support.

### Enquiry

Provides a form where individuals and businesses can submit service requests and provide relevant vehicle or fleet information.

### Contact

Displays the office address, telephone numbers, WhatsApp contact, business hours, location image, map link, and contact form.

## Technologies Used

- HTML5 for the page structure
- CSS3 for styling and responsive layouts
- Local images for branding and website content
- Responsive design for different screen sizes

## How to Run the Website

No installation or database is required. Open `index.html` in a web browser, or use a local development server such as the VS Code Live Server extension.
